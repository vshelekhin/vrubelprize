# HOT OR NOT — десктопный пилот

Отдельная тестовая страница рабочего сайта. Исходники и основной домен премии не синхронизируются этой задачей.

Вариант 2 с чёрным фоном и золотыми акцентами — `hot-or-not/2/`; короткий вход — `/vrubelprize/2/`. Он использует общие `app.js`, `config.js` и изображения первого варианта через `<base href="../">`: голоса, имя и прогресс общие для обоих оформлений. Тема находится отдельно в `2/theme.css`.

- 20 акварелей Алёны Кругловой и Ивана Крюкова; картинки в `images/` — облегчённые копии с сохранёнными пропорциями.
- Вход по произвольному имени, без e-mail и GetCourse. Одинаковое имя без учёта регистра и лишних пробелов продолжает прежнюю историю; это не проверка личности.
- Все выборы и общий Эло сохраняются обработчиком Google Apps Script в закрытую таблицу организатора. Данные голосования не хранятся в GitHub.
- Всего 20 сравнений для каждого имени, затем «Спасибо за участие!» и окончательное завершение. Дополнительных раундов и кнопок продолжения нет. Сервер не принимает 21-й выбор и не возобновляет завершённое голосование при повторном входе.
- Приоритет картин с меньшим числом показов; случайный выбор среди равных вариантов и случайная сторона. Пара не повторяется для того же имени.
- Обращение к зрителю на «вы» во всех текстах, подсказках и сообщениях об ошибках обоих вариантов.
- Начальный рейтинг 1000, K=24. Расчёт идёт на сервере по журналу в порядке записи, без округления внутренних значений.
- Все пары назначаются сервером заранее и сохраняются в скрытом K на листе «Участники». Следующие картинки подгружаются заранее. Между выборами нет ожидания ответа Google.
- Каждый выбор сначала сохраняется отдельной записью в localStorage, затем отправляется в фоне пакетами. Подтверждаются только записанные сервером ID; потеря ответа и перезагрузка безопасны для повторной отправки. Старый неподтверждённый голос из предыдущей версии переносится в очередь.
- После 20-го выбора «Спасибо» появляется только после подтверждения всех голосов. Ошибка оставляет очередь в браузере и позволяет повторить отправку. Страница предупреждает о закрытии, пока есть неподтверждённые голоса.
- Рейтинг пересчитывается отдельно раз в минуту функцией `rebuildRanking`, либо вручную через меню таблицы; запись голосов не ждёт обновления рейтинга.
- Картины целиком, без обрезки; фактическая высота обеих одинакова. Увеличение по кнопке, выбор также стрелками клавиатуры.
- Мобильная компоновка отложена по просьбе пользователя; этот пилот рассчитан на десктоп.

`config.js` содержит публичный адрес обработчика, без секретов. Текст Apps Script, тесты, реестр источников и отчёт находятся локально в проекте `hot-or-not-pilot/`, за пределами публикуемого каталога.

В таблице: «Картины», «Голоса», «Рейтинг», «Участники», «Инструкция». Меню «HOT OR NOT → Пересчитать рейтинг» восстанавливает рейтинг по журналу. Значение FALSE в последнем столбце журнала исключает голос из пересчёта.
