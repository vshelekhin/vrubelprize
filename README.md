## Порядок работы

1. Правки делаем и проверяем здесь; публикация этого репозитория меняет только рабочий сайт.
2. Перед новым переносом с боевого сайта сравниваем историю обоих репозиториев. Не перезаписываем местные наработки целиком.
3. Только после прямой команды Владимира переносим согласованные изменения в боевой репозиторий. Убираем исключительно служебные отличия рабочей копии: префикс `/vrubelprize/`, запрет индексации новых страниц и перенаправление на действующую форму. Исходный `noindex` документов сохраняем.
4. Перед отправкой проверяем diff с актуальным боевым `main`; не заменяем сайт старым экспортом React. Commit + push в боевой `main` запускает публикацию vrubelprize.ru.

Каталог `v6/` и его общие изображения и скрипт галереи сохранены без изменений. Новая галерея использует отдельный `current-assets/jury/gallery-viewer.js`. Старые версии v1–v5 при необходимости доступны в истории до этого переноса: `bdfceb97116f5a770fc990e9ec8240853e5c31e3`.
