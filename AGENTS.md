# Рабочая копия vrubelprize.ru

- Сначала прочитай README.md в этом репозитории.
- Актуальная рабочая версия — статический сайт в корне этого репозитория, не старые React-компоненты в родительской папке. Не запускай старый экспорт поверх корня.
- Не менять `v6/` и его существующие общие ассеты без прямого запроса пользователя. `jury/gallery-viewer.js` принадлежит сохранённой версии; новая галерея — `current-assets/jury/gallery-viewer.js`.
- Push сюда публикует только https://vshelekhin.github.io/vrubelprize/. Боевой репозиторий `kosenkoandrey/vrubelprize.ru` изменять и публиковать только по отдельной прямой команде пользователя.
- Перед обновлением из боевого репозитория получить актуальную историю, сравнить её с базой переноса из README и сохранить местные правки. Не делать слепую полную синхронизацию.
- Кнопки заявки оставлять на https://vrubelprize.ru/apply/. Это реальная форма: не отправлять тестовые заявки без отдельного разрешения.
- Никогда не копировать сюда серверные PHP-файлы, конфигурацию админки, данные участников или секреты.
- Перед выпуском проверить внутренние ссылки с префиксом `/vrubelprize/`, страницы документов, галереи и неизменность сохранённой v6.
